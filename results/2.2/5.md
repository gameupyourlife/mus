## Histogram interpretation

The waiting-time and service-time histograms are generated by
`blatt2/plot_waiting_service_histograms.py` and saved as
`results/waiting_service_histograms.png`.

The service-time histogram is concentrated in one bin for each run because
service time is deterministic: it is 9, 10, or 11 seconds.

For a 9-second service time, every customer finishes before the next arrival,
so the waiting-time histogram is concentrated at zero. The queue occupancy is
also zero, while server utilization is 0.9.

For a 10-second service time, arrivals and completions occur at the same
timestamps. There is no positive-duration waiting interval, so waiting time
and queue occupancy remain zero. The server utilization is 1.0.

For an 11-second service time, customers arrive faster than they can be
served. The waiting-time histogram spreads over an increasingly large range,
and the queue-occupancy histogram shifts toward larger values as T increases.
The server remains busy, so utilization is 1.0.
